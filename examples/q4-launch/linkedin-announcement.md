# LinkedIn announcement (draft 3)

Plans, briefs, calendars, reports. And every time, I open it in a code editor, squint at the asterisks, and hunt for the checkbox I need to tick.

**So I built the reader I wanted.** It opens the file, makes it look like a finished document, and lets me tick the box right there.

- Click a checkbox, it saves to the file
- Copy for LinkedIn without the stray asterisks
- Shrink a folder of images to WebP, metadata scrubbed
