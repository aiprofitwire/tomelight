# Example workspace

A small, made-up launch folder to try Tomelight with. Open this folder in Tomelight (`⇧⌘O`), then:

1. Open `00-START-HERE.md` and tick a few boxes, including the ones inside the table.
2. Press `⌘2` for Write mode and edit it like a doc.
3. Open `linkedin-announcement.md` and use **Copy for… → Plain text for social**.
4. Open `landing-page.html` to see an HTML page render with its JavaScript running.
5. Press `⇧⌘I` for Image Studio and drop in the photos from `images/`. `IMG_4821.jpg` carries demo GPS data (the Eiffel Tower) so you can see the metadata scrubber at work.

Every file here is fictional sample content.
