# Research Brief: Markdown in 2026

## Why Markdown won

Markdown is the default output format for most AI assistants[^1]. It is plain text, so it survives copy and paste, version control and every operating system.

## The problem

Plain text is great for machines and rough for humans. A 400 line plan with nested lists and tables reads like a wall of symbols in a code editor.
